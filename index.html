From email to the code you need

  1. Connect Gmail through Google’s consent screen.
  2. The extension reads recent messages in your chosen time window.
  3. It detects verification codes and sign-in links locally.
  4. You choose which code to copy or which link to open.

Read-only access

The Gmail integration requests gmail.readonly. Reading message bodies is necessary because codes and links often appear inside an email.

It does not request permission to send, change, or delete email. OAuth credentials are stored through Raycast’s secure OAuth API.

A community extension, with inspectable code

This page documents the Gmail integration maintained by Aaron Schaub (taschaub), a contributor to the open-source 2FA Code Finder extension. The Raycast extension also supports iMessage and Apple Mail. This is a community project, independent of Google and Raycast Technologies Ltd.

Upstream extension repository · Contributor’s extension fork · Source for this repaired Gmail integration

Google OAuth verification is being prepared. Accounts enrolled in Google’s Advanced Protection Program may remain unable to connect until Google approves the integration. This site does not claim Google verification or endorsement.

Your data stays under your control

The Gmail integration has no developer-operated email-processing server. Message contents and extracted codes are processed in Raycast on your Mac. Copying a code uses your system clipboard; opening a link uses your browser.
