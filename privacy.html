2FA Code Finder for Raycast — Gmail integration

Effective October 19, 2026 · Maintained by Aaron Schaub

What this policy covers

This policy describes the Gmail integration and repaired extension source linked from this website. It does not replace the privacy policies of Google, Raycast, GitHub, your browser, or your operating system, and it does not describe every third-party fork of the extension.

Contact: tim.aaron.schaub@gmail.com.

Google data accessed and its purpose

With your permission, the extension requests https://www.googleapis.com/auth/gmail.readonly. It reads recent Gmail message identifiers, sender, subject, dates, snippets and message bodies to find one-time verification codes and sign-in or verification links. Account profile information can be used to identify the connected mailbox. This read-only permission also permits reading Gmail settings, although this integration does not use settings-management features.

Reading bodies is necessary because codes and links can be in the body rather than in message headers. The extension does not request permission to send, edit, or delete email. You configure the message lookback window in Raycast; each fetch requests at most 50 message identifiers.

Processing, storage and sharing

Google sign-in and consent take place through Google. The extension exchanges the authorization code directly with Google using PKCE, then requests email directly from the Gmail API. No developer-operated server processes or receives your Gmail messages, verification codes, or OAuth credentials as part of this integration.

Access tokens and refresh tokens are stored through Raycast’s secure OAuth storage API. Client IDs and account configuration are stored in Raycast preferences or local storage. The extension processes message contents and detected codes in memory and does not persist an email-body database.

The integration does not sell Gmail data, use Gmail data for advertising, or use Gmail data to train AI models. The integration’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

When you choose to copy a code, link or message details, that content is placed on the system clipboard. When you open a verification link, your browser visits that destination. Clipboard history, sync, backups, Raycast host functionality, and your browser’s own handling are controlled by their respective settings and privacy policies. The extension contains diagnostic error logging; avoid sharing logs that contain personal information.

Disconnecting and deletion

You can disconnect the Gmail provider in Raycast’s extension preferences. The multi-account development fork also offers account removal in Manage Email Accounts. Disconnecting removes locally stored OAuth credentials through Raycast’s OAuth API; removing a configured account also removes its saved account entry. This does not delete your messages in Gmail.

To revoke Google’s authorization independently of local token removal, remove this application from your Google Account’s third-party connections. After the extension’s process ends, its in-memory email data is no longer retained by that process. Clipboard entries, host-managed backups and diagnostic logs may remain until you remove them using the relevant application or operating-system controls.

This website and support

This website is a static GitHub Pages site. It includes no sign-in form, analytics script, tracking pixel, or advertising code, and does not ask for Gmail credentials or verification codes. GitHub may process request information while hosting the site under the GitHub Privacy Statement.

If you contact the maintainer by email or in a public GitHub issue, the information you choose to provide is handled by those services. Do not send live verification codes, tokens, passwords, or private email contents in a support request.

Changes

Changes to the integration’s data handling will be reflected in this policy, with an updated effective date and a public source history in the linked GitHub repository.
